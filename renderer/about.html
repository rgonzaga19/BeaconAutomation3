▸ ABOUT THIS APPLICATION

Beabots is a desktop automation tool built to speed up the encoding of PhilHealth Beacon claims. It handles the repetitive parts of claims processing so encoders can move through submissions faster and with fewer errors.

Developer
Romel Gonzaga
Companion App
SOA Excel Generator
Core Features
  • Auto Draft — automated drafting of claim entries
  • CF2 — automated encoding for PhilHealth CF2 forms
  • CF4 — automated encoding for PhilHealth CF4 forms
  • Upload SOA — automated upload of Statement of Account files
  • Medicine Mapping — maps medicines to their correct claim codes/entries
